## 📋 Описание проекта

**BRUTAL STYLE** — одностраничный сайт барбершопа в бруталистском стиле с интеграцией Telegram Mini App.
**Стек Frontend:** HTML + CSS + Vanilla JS (ES-модули) + TypeScript через JSDoc.
**Стек Backend:** Cloudflare Workers (Node.js без зависимостей).
**Пайплайн:** Vitest + Playwright + Biome + Wrangler.

---

## 🏗 Архитектура и Безопасность (Zero Trust)

Проект использует гибридную архитектуру для обхода блокировок РКН и защиты от спама.

1. **Frontend (GitHub Pages):** Раздает статику. Использует локальную копию SDK Telegram (`telegram-web-app.js`), чтобы не зависеть от заблокированного `telegram.org`.
2. **Backend (Cloudflare Worker):** Выступает как прокси к `api.telegram.org`.
   - **Секреты:** Токен бота и Chat ID хранятся в `wrangler secret`, в коде их нет.
   - **Валидация `initData`:** Воркер проверяет HMAC-SHA256 подпись от Telegram. Заявки из браузера (без `initData`) пропускаются с пометкой `🌐 Из браузера`. Поддельные заявки из Telegram (неверная подпись) пропускаются с пометкой `⚠️ Невалидный Telegram`.
   - **Защита от XSS:** Все входящие данные экранируются (HTML escape) перед отправкой в Telegram.
   - **Формирование сообщения:** Текст сообщения собирается на сервере, клиент не может подменить `chat_id`.

## 🛠 Инженерный пайплайн (Команды)

### Фронтенд

| Команда                              | Что делает                       |
| :----------------------------------- | :------------------------------- |
| `npm test`                           | Запускает юнит-тесты (Vitest)    |
| `npm run e2e`                        | Запускает E2E-тесты (Playwright) |
| `npx @biomejs/biome check --write .` | Линтинг и автоформатирование     |
| `npx serve -p 3000`                  | Локальный сервер для E2E-тестов  |

### Бэкенд (Cloudflare Worker)

| Команда                                 | Что делает                                |
| :-------------------------------------- | :---------------------------------------- |
| `cd tg-barbershop-proxy`                | Переход в папку воркера                   |
| `npx wrangler deploy`                   | Деплой воркера в облако Cloudflare        |
| `npx wrangler tail`                     | Просмотр логов воркера в реальном времени |
| `npx wrangler secret put BOT_TOKEN`     | Добавление/обновление секрета токена      |
| `npx wrangler secret put ADMIN_CHAT_ID` | Добавление/обновление секрета чата        |

## 🤖 Инструкции для ИИ (Правила игры)

**Внимание, ИИ!** При генерации кода для этого проекта строго соблюдай следующие правила:

1. **Никаких токенов на клиенте:** Никогда не пиши `BOT_TOKEN` или `CHAT_ID` в файлах `app.js` или `index.html`. Только `env.BOT_TOKEN` внутри `worker.js`.
2. **Ванильный JS + JSDoc:** Не предлагай React, Vue или TypeScript-компилятор. Используй ES-модули и `@ts-check`.
3. **Безопасность превыше всего:** Любой текст, приходящий от пользователя, должен проходить через функцию `escapeHTML` на стороне воркера.
4. **Локальный SDK:** Не подключай `https://telegram.org/js/telegram-web-app.js`. Используй только локальный файл `./telegram-web-app.js`.
5. **Кэш-бастинг:** При изменении `app.js` не забывай напоминать пользователю обновить версию в `index.html` (например, `app.js?v=4`).
6. **Осторожно с fetch:** В Telegram Desktop на Windows `fetch` может блокироваться прокси. Всегда предусматривай fallback и логирование ответов сервера.

## 🎨 Реализованные фичи

1. **Кастомный курсор-ножницы** (SVG, плавная интерполяция, скрытие при фокусе).
2. **Прогресс-бар скролла** и кнопка "Наверх".
3. **Hero-секция** с фоновым видео.
4. **Бегущая строка (Ticker)** (2 штуки).
5. **Счётчики статистики** (IntersectionObserver).
6. **Мастера (12 карточек)** с модальными окнами.
7. **Форма бронирования** с маской телефона.
8. **Telegram Mini App:** Автоподстановка имени, нативная кнопка `MainButton`, адаптация под тему.
9. **Умная отправка заявок:** Работает и в браузере (с пометкой), и в Telegram (с `@username`).
