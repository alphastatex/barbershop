## 📋 Описание проекта

**BRUTAL STYLE** — одностраничный сайт барбершопа в бруталистском стиле.  
**Стек:** HTML + CSS + Vanilla JS (ES-модули) + TypeScript через JSDoc

**Дизайн:** Чёрный фон, красный акцент (#d4121e), моноширинный шрифт Space Mono, кастомный курсор-ножницы

## 🎨 Реализованные фичи

### 1. Кастомный курсор-ножницы

- SVG-ножницы летают за мышкой с плавной интерполяцией (коэффициент 0.22)
- Анимация "щёлка" при клике (CSS keyframes `snipTop`/`snipBottom`)
- Скрывается при фокусе на полях ввода (модалка бронирования)
- `mix-blend-mode: difference` для контраста на любом фоне
- `z-index: 99999` — поверх всего, кроме крестика закрытия модалки мастеров (`z-index: 100002`)

### 2. Прогресс-бар скролла

- Красная полоска сверху (`z-index: 100001`)
- Заполняется от 0% до 100% по мере прокрутки
- Свечение через `box-shadow`

### 3. Кнопка "Наверх"

- Появляется после скролла (`opacity: 0 → 1`)
- Плавный возврат через `scroll-behavior: smooth`

### 4. Hero-секция с видео

- Фоновое видео (`hero-bg.mp4`) с autoplay + loop
- Градиентный оверлей
- Вертикальная надпись "26" справа (`writing-mode: vertical-rl`)
- CTA-кнопка "Записаться →"

### 5. Бегущая строка (Ticker)

- Два тикера: основной (красный) и вторичный (белый)
- CSS-анимация `tickerScroll` (40s и 50s)
- Разделители "✦"

### 6. Манифест

- Центрированный блок с крупной типографикой
- Scroll-reveal анимация

### 7. Услуги (4 карточки)

- Стрижка, Борода, Королевское бритьё, Комплекс
- Hover-эффект: фон становится красным, текст чёрным
- Таблица шагов услуги с временем

### 8. Счётчики статистики

- 12 мастеров, 8000+ клиентов, 8 лет опыта, 100% качества
- Анимация чисел через `IntersectionObserver` (threshold: 0.5)
- Шаг анимации: `Math.ceil(target / 40)`, интервал 25ms

### 9. Мастера (12 карточек)

- 3 видимых + 9 скрытых (кнопка "Показать всех 12 мастеров")
- Фото в круглых аватарах (чёрно-белые → цветные при hover)
- **Кликабельные карточки** → модальное окно с деталями
- Модалька: фото слева, текст справа, статистика (специализация, опыт, клиенты, напиток)
- Закрытие: крестик, клик по фону, Escape
- Кастомный курсор остаётся видимым внутри модалки

### 10. Форма бронирования

- Модальное окно с полями: Имя, Телефон, Услуга, Мастер, Комментарий
- **Маска телефона**: `9991234567` → `+7 (999) 123-45-67` (функция `formatPhone` в `utils.js`)
- Валидация обязательных полей
- Сообщение об успехе после отправки

### 11. Футер

- 4 колонки: Адрес, Часы, Контакты, Соцсети
- Копирайт "© 2026 BRUTAL STYLE · DESIGNED WITH ✦ IN MOSCOW"

### 12. Scroll-reveal анимации

- Класс `.reveal` + `.reveal-delay-1/2/3/4`
- `IntersectionObserver` с threshold 0.15
- Плавное появление снизу (`translateY(40px) → 0`)

### 13. Фавикон

- Чёрный круг с красными ножницами (SVG data URI)
- Отлично виден на белом фоне вкладки

### 14. Адаптивность

- `@media (max-width: 768px)` для всех секций
- Мобильная версия модалки мастеров: 1 колонка (фото сверху)
- Отключение кастомного курсора на мобильных

### 15. Доступность

- `prefers-reduced-motion: reduce` — отключает анимации
- `focus-visible` outline для клавиатурной навигации
- `aria-label` на кнопках закрытия

## 🎯 Ключевые решения и почему

### Почему `for...of` вместо `forEach`?

Biome (линтер) рекомендует `for...of` для лучшей производительности и читаемости. При больших массивах `forEach` может создавать проблемы с `filter`/`map`.

### Почему JSDoc вместо TypeScript?

Проект на чистом JS, но нужна типизация. JSDoc + `@ts-check` даёт проверку типов без необходимости настраивать `tsconfig.json` и компилятор.

### Почему Playwright, а не Cypress?

Playwright быстрее, поддерживает несколько браузеров из коробки, лучше работает с современными фичами (Shadow DOM, iframes).

### Почему модалка мастеров закрывается по `not.toHaveClass(/active/)`, а не `not.toBeVisible()`?

Потому что наш JS убирает класс `active`, а CSS-переход (`opacity 0.4s`) делает элемент невидимым с задержкой. Проверка класса — мгновенная и надёжная.

### Почему крестик модалки мастеров имеет `z-index: 100002`?

Кастомный курсор-ножницы имеет `z-index: 99999`. Крестик должен быть поверх курсора, чтобы клик всегда проходил.
